# Запуск бота анализа Instagram-конкурентов

Бот собирает данные о конкуренте в Instagram (профиль, закрепы, хайлайты, Reels,
посты), анализирует их через GPT и пишет результат в Google-таблицу.

## 1. Зависимости

Нужен Python 3.10+. Установите пакеты:

```bash
cd instagram_research_test
pip install -r requirements.txt
```

Для анализа видео (кадры из Reels) нужен `ffmpeg`:

```bash
brew install ffmpeg        # macOS
# или: sudo apt install ffmpeg   (Linux)
```

## 2. Настройка .env

Скопируйте шаблон и заполните 8 переменных:

```bash
cp .env.example .env
```

| Переменная | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | у @BotFather: `/newbot` |
| `TELEGRAM_ALLOWED_IDS` | напишите боту `/start` — он покажет ваш chat_id |
| `OPENAI_API_KEY` | platform.openai.com/api-keys |
| `APIFY_TOKEN` | console.apify.com/settings/integrations |
| `INSTAGRAM_SESSION_COOKIE` | cookie залогиненного Instagram (DevTools → Cookies) |
| `GOOGLE_SHEETS_WEBAPP_URL` | URL `/exec` развёрнутого Apps Script Web App |
| `GOOGLE_SHEETS_SYNC_SECRET` | значение `SYNC_SECRET` из Script Properties |
| `GOOGLE_SHEETS_SPREADSHEET_ID` | ID из URL таблицы (уже заполнен по умолчанию) |

## 3. Запуск бота

```bash
cd instagram_research_test
python3 scripts/telegram_bot.py
```

Бот работает в режиме polling. Чтобы остановить — `Ctrl+C`
(или `pkill -9 -f telegram_bot.py`).

## 4. Что увидит пользователь (Катя)

1. `/start` → кнопки **«📋 Мои конкуренты»** и **«➕ Добавить нового»**.
2. В списке конкурентов у каждого видна свежесть данных и счётчики строк.
3. Тап по конкуренту → **экран аккаунта**: свежесть 7 блоков
   (✅ свежее / ⚠️ устарело / ⚪ нет данных) и кнопки:
   - **🔄 Обновить устаревшее** — пересобрать только устаревшие/недостающие блоки;
   - **♻️ Перезаписать всё** — полный прогон, строки аккаунта в таблице заменяются;
   - **➕ Дописать** — полный прогон, строки добавляются к существующим;
   - **⚙️ Настройки и запуск** — экран с галочками (блоки, типы постов, период,
     фильтр контента, листы) + Смета / Dry-run / Запуск;
   - **🗑 Удалить** — убирает аккаунт из списка, папку с данными и строки из таблицы.
4. Во время прогона сообщение обновляется прогрессом по стейджам
   (✅ готово / ⚙️ выполняется / ⏳ ожидает / ❌ ошибка).
5. По завершении — итоговый отчёт со ссылкой на таблицу и сводкой по аккаунту.

## 5. Проверка без затрат (dry-run)

Перед реальным прогоном можно прогнать пайплайн вхолостую — внешние API
не вызываются, файлы и таблица не меняются:

```bash
python3 run.py --account vlada_kliuiko --dry-run
```

Должны пройти все 17 стейджей со статусом `dry_run`. В боте тот же режим —
кнопка **🧪 Dry-run** на экране настроек.

## 6. Известные ограничения

- **Один прогон за раз.** Пока идёт анализ, новый запуск заблокирован
  (бот предупредит «Уже выполняется анализ…»).
- **Сторис (стейдж 09)** требуют валидной `INSTAGRAM_SESSION_COOKIE`. Куки
  протухают — при ошибке стейджа 09 обновите значение в `.env`.
- **Устойчивость к пустым блокам.** Если у конкурента нет закрепов / хайлайтов /
  ссылки, соответствующий стейдж помечается ❌, но прогон продолжается и
  доходит до записи в таблицу. Код выхода будет ненулевым — бот покажет
  «завершён с ошибками», это нормально для частично пустых профилей.
- **Стоимость.** Apify и OpenAI платные. Перед запуском смотрите кнопку
  **💰 Смета**.

## 7. Передеплой Apps Script

Логика записи и удаления в таблице — в `apps_script/stage5d3_write_google_sheets_webapp.gs`.
После изменений `.gs` его нужно передеплоить в Google:

1. Открыть проект Apps Script, привязанный к таблице.
2. Вставить актуальное содержимое `.gs`.
3. **Deploy → Manage deployments → Edit → New version → Deploy**
   (URL `/exec` сохраняется — менять `GOOGLE_SHEETS_WEBAPP_URL` не нужно).
4. Убедиться, что в **Project Settings → Script Properties** задан `SYNC_SECRET`,
   совпадающий с `GOOGLE_SHEETS_SYNC_SECRET` в `.env`.

> Режим **«Дописать»** (`write_mode=append`) и **удаление** аккаунта
> (`mode=delete_account`) работают только после передеплоя свежей версии `.gs`.
