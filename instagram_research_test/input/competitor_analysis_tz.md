## **ТЗ: анализ Instagram конкурента**

### **Цель анализа**

Понять, как конкурент упаковывает продукт, какие смыслы выносит на первый экран (если есть сайт), какие доказательства использует, куда ведет аудиторию и как дальше устроена воронка: профиль → highlights → закрепы → CTA → сайт / бот / лид-магнит / продажа.

### **Что фиксируем**

#### **Описание профиля**

Посмотреть:

* что вынесено в имя;  
* для кого продукт / эксперт;  
* какую проблему решает;  
* какой результат обещает;  
* какие аргументы использует;  
* есть ли социальные доказательства;  
* есть ли конкретика: цифры, кейсы, опыт, клиенты, результаты;  
* есть ли оффер;

#### **CTA в bio**

Зафиксировать:

* какой призыв к действию;  
* куда ведет ссылка;  
* ведет ли он в продажу, прогрев, бот, лид-магнит или сразу на продукт.

#### **Воронка**

Перейти по ссылке и разобрать, куда ведут пользователя.Возможные варианты:

* лендинг курса;  
* Taplink / мультиссылка;  
* Telegram-бот;  
* лид-магнит;  
* бесплатный урок;  
* вебинар;  
* диагностика;  
* консультация;  
* tripwire;  
* сразу покупка;

#### **Анализ highlights**

* названия highlights;  
* порядок расположения;  
* какие темы вынесены первыми;

**Содержание каждого highlight**

* о чем он;  
* какая задача у него в профиле;  
* что человек должен понять после просмотра;  
* есть ли и куда ведет CTA;  
* какие формулировки CTA;

#### **Анализ трех закрепленных постов**

* тема поста;  
* почему, вероятно, он закреплен;  
* какой хук в начале;  
* какие ключевые смыслы в тексте;  
* какие доказательства есть;  
* какой CTA;  
* какую роль выполняет:  
  * знакомит;  
  * объясняет позиционирование;  
  * продает;  
  * показывает кейсы;  
  * отвечает на возражения;  
  * ведет в лид-магнит;  
  * усиливает экспертность;

#### **Анализ воронки**

Нужно пройти путь пользователя от Instagram до следующего шага.

Зафиксировать путь. Например: Instagram → bio → лид-магнит → Telegram-бот → серия сообщений → оффер курса → заявка.

**Что анализируем**

* первый шаг;  
* что обещают за переход;  
* где собирают контакт;  
* как быстро появляется продажа;  
* есть ли прогрев;  
* какие продукты предлагают;  
* есть ли tripwire;  
* есть ли основной продукт;  
* есть ли консультация / диагностика;  
* какие возражения снимают;  
* какие боли/посылы используют;

#### **Если есть сайт**

**Первый экран**

Зафиксировать:

* главный заголовок;  
* подзаголовок;  
* для кого продукт;  
* какой результат обещают;  
* какой CTA;  
* есть ли визуал продукта / эксперта;  
* есть ли социальные доказательства;  
* понятно ли, что продают.

**Второй и третий экран**

Посмотреть:

* что объясняют сразу после оффера;  
* какие боли / желания раскрывают;  
* какие аргументы ставят первыми;  
* есть ли блок “для кого”;  
* есть ли доказательства;  
* есть ли описание продукта;  
* есть ли отзывы / кейсы;  
* есть ли повтор CTA.

**Итог по сайту**

Сформулировать:

* на чем строится продажа;  
* какие смыслы вынесены наверх;  
* какие аргументы считаются главными;  
* насколько быстро понятно, что купить и зачем;  
* что можно забрать себе как прием.

#### **Если ведут в бот / лид-магнит**

* что человек получает в боте;  
* какие первые сообщения;  
* есть ли сегментация;  
* какие кнопки;  
* сколько сообщений в цепочке;  
* когда появляется продажа;  
* как формулируется оффер;  
* какие боли / желания используют;  
* какие доказательства дают;  
* есть ли дедлайн / ограничение / бонус;  
* куда ведет финальный CTA.
