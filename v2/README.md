# Focusboard V2 — фазовая машина дня

## Установка как приложение + автозапуск

```bash
cd ~/Claude/Projects/focus-board/v2
npm run electron:build          # соберёт «Focusboard V2.app» в v2/release
bash install-autostart.sh       # /Applications, launchd v2-api, объекты входа
```

Скрипт включает автозапуск Focusboard V2 и выключает автозапуск старого Focus Board
(launchd-бэкенд v1 на :3001 не трогается — на нём живут данные).
Дальше галочки автозапуска обоих приложений — в Настройках Focusboard V2.

Не рестайлинг, а другой продукт на тех же данных. Приложение живёт в фазах дня,
а не в дашборде: **Утро → День → Фокус-туннель → Вечер**. Списки задач убраны
со сцены в слой «Библиотека», статистика превращена в «Пульс».

**Данные общие с v1.** Рабочая версия не тронута, обе запускаются одновременно.

## Запуск


Что поднимается: бэкенд v1 на :3001 (переиспользуется, если уже запущен),

собранный фронтенд на :4174.

## Как устроен день

**Утро** — визард из трёх шагов: настроение и цель дня → выбор 1–3 «миссий»
(главных задач) из библиотеки или с нуля → бюджет часов на каждую.
Появляется автоматически в новый день, можно пропустить.

**День** — только миссии, крупными карточками: прогресс к бюджету, «В фокус»,
готово. Внизу — нить дня: реальная лента сессий на шкале 6:00–24:00 с отметкой
«сейчас». Процент дня в шапке. После 19:00 появляется «Завершить день».

**Фокус-туннель** — старт таймера уводит в полноэкранную сессию: дышащий
янтарный амбиент, гигантский таймер, намерение сессии, шаги задачи с чек-боксами,
прогресс бюджета, помодоро. Пауза — экран дыхания с подсказкой отдыха и счётчиком
паузы. Space — пауза/продолжить.

**Вечер** — итог: время в фокусе, миссии закрыты/нет, лента дня, пара строк
рефлексии в дневник и выбор миссий на завтра — утром они уже ждут.

## Слои (поверх любой фазы)

- **Библиотека** (⌘L) — все задачи по направлениям: поиск, приоритеты,
  ★ в миссии дня, ▶ в фокус, клик — редактор-drawer. «Когда-нибудь» — отдельно.
- **Пульс** — живая статистика: карта фокуса час×день за 90 дней (реальные
  паттерны: лучший час и день подсвечены), инсайты потока (типичная сессия,
  лучшие часы), баланс направлений за 30 дней. Классическая статистика — по кнопке.
- Дневник, настройки, архив, корзина, план недели, стендап — в меню «⋯».

## Новые механики и данные

- Таблица `v2_day_missions` (создаётся v2-api, v1-схема не изменена ни на байт).
- Endpoints: `/api2/missions`, `/api2/heatmap`, `/api2/flow`,
  `/api2/today-sessions`, `/api2/direction-balance`.
- Таймер, сессии, задачи, направления, журнал, геймификация — всё через
  оригинальный API v1: старая версия видит всю работу, сделанную в v2, и наоборот.

## Разработка

`frontend/node_modules` ставились под Linux (песочница сборки). Для live-разработки:

```bash
cd v2/frontend && rm -rf node_modules && npm install
npm run dev                      # vite :5174
V2_DEV=1 npm run electron:dev    # окно смотрит на :5174
```

Пересборка: `cd v2/frontend && npm run build`.
Дизайн-токены: `tailwind.config.js` + `src/index.css` («тихая кабина»:
тёплый графит #141312, янтарь #e0a458, слои глубины, mono-цифры).
